# 手術影像分析工作站介面

以深海軍藍降低長時間檢視的亮度，青綠色標示主要操作；影片維持原色，ROI 與階段色彩保留原本語意。字體、間距、邊框、選取狀態集中在 `utils/workstation_theme.py`，分析與資料存取仍由既有處理函式負責。

## 工作區配置

- 上方：載入影片、分析資料夾、目前檔名與實際結果路徑。長檔名只使用可伸縮區域，操作按鈕保持可見。
- 模式列：OCR 數值標註／手術階段分析，以及上一影格／目前影格 ROI 對比。
- 中央：等比例手術影像與可捲動的事件表格，保留雙擊或 Enter 編輯、右鍵選單、模式專屬欄位。
- 下方：播放／暫停、精確跳幀、原有多軌道時間軸，以及狀態訊息與快捷鍵提示。

初始視窗 1440×900，最小 1050×720；最大化可擴大影片。不同模式的事件表格依原有設定使用 320／400／700 像素寬度，較寬表格仍可水平捲動。沒有載入影片時顯示操作提示，載入後以完整影片影格取代。

事件表格顯示實際筆數與交錯列底色，沒有事件時顯示提示；影像標頭顯示來源解析度及 FPS。檔名與結果路徑可停留查看完整內容。主要按鈕支援 Enter 和滑入回饋。

跳幀欄位檢查整數與有效範圍，以欄位邊框與底列訊息提示，修正後恢復正常。Ctrl+L 預填目前幀號；Ctrl+S 的儲存成功訊息只顯示在底列，保留按鈕儲存時原有的確認視窗。編輯視窗預選文字、支援 Esc 取消，保存時維持原時間格式與其他欄位。

## 驗證與維護

### 鍵盤與動態回饋

F1 或右上角「快捷鍵」按鈕開啟完整操作表，與實際按鍵綁定共用 `utils/workstation_interactions.py` 的單一清單。常用操作為 Ctrl+O 載入、Ctrl+Shift+O 選擇結果目錄、Ctrl+S 儲存、Ctrl+L 跳幀欄位、Alt+1／2 切換模式、Alt+↑／↓ 切換區域；Shift+←／→ 約移動一秒，Home／End 前往影片首尾。Enter 編輯選取事件，在跳幀輸入框則執行跳轉；Esc 返回影片鍵盤操作。

文字輸入框、下拉選單、數值輸入與滑桿保留原生按鍵行為，按鈕的空白鍵不會同時觸發播放。事件表格在原生按鍵處理之前接手導航，避免一次按鍵移動兩筆。

幀號與時間分開顯示，時間以時／分／秒／百分之一秒呈現，依影片實際 PTS 而非平均 FPS 換算。成功逐幀或跳轉引起的數值變動會觸發一次 320 毫秒青綠淡出，快速重複操作只保留一組計時器。連續播放不觸發脈衝；F1 面板可關閉動態回饋。拖曳目標先顯示在底列，放開並解碼成功後才提交畫面與數值。定位原因、演算法及驗證範圍見[影格與時間同步](viewer-timing.md)。

`tests/check_workstation_gui.py` 使用暫存 MJPEG 影片、機型 2 紀錄、OCR 變化與手術階段資料，在真實 Tk 視窗驗證：

1. 載入按鈕接通影片、機型與事件資料。
2. Return 跳幀、方向鍵、播放／暫停仍正常。
3. 模式切換保留欄位、時間軸與儲存按鈕顯示邏輯。
4. 編輯對話框及儲存按鈕輸出原有相鄰結果格式。
5. 1050×720、1440×900、1850×1000 的主要控制項均在視窗範圍內，暫停影格保持不變。
6. 一般文字、次要文字、選取列與主要按鈕文字對比至少 4.5:1。
7. 自動選取不改變影格、片尾定位有效，ROI 預覽後的播放像素對應下一幀。
8. 輸入錯誤、非阻斷快捷鍵儲存、Enter 按鈕操作、Esc 取消、完整路徑提示與事件摘要。

### 選取與播放位置的邊界

表格自動選取只反映目前影格，不代表使用者要求跳轉。Tk 的 `TreeviewSelect` 會排隊，立即解綁再綁回仍可能收到先前事件，因此同步選取使用帶世代編號的尾端事件，在該批選取事件處理後才清除標記。真實點擊與上下鍵仍可跳轉。

ROI 對比讀取上一幀時，必須保存並還原主解碼器位置；否則開始播放時，畫面會重播目前幀，但幀號已前進。片尾定位則限制在 `total_frames - 1`。本輪以修復前會失敗的測試重現這些案例，再驗證修復：階段中途選取、第一筆事件不在 0、片尾、ROI 預覽後的下一幀像素。這些是檢視器操作修正，並未改動分析管線。

2026-10-24：完整離線／GUI 測試共 151 項通過，包含快捷鍵、輸入焦點保護、事件單步切換、F1 面板、幀號／時間高亮、PTS 索引、VFR 時間軸同步、正確參照圖、播放時 ROI 預覽及滑桿鍵盤定位。另以模擬計時器驗證淡出在 320 毫秒排程後結束、快速操作只保留一組排程。分析 golden 回歸以 4 部影片、`--rtol 0` 比對原有輸出；GUI 互動另由前述真實視窗測試涵蓋。95 部來源影片的 2,706 個 STAGE 起訖點也已全部核對一致，詳見[影格與時間同步](viewer-timing.md)。
